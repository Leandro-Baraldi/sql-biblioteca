📘 Sistema de Biblioteca – SQL (Atividade 4)

Repositório contendo scripts SQL da Atividade 4 do projeto de Banco de Dados, incluindo criação das tabelas, inserção de dados, consultas e manipulação (UPDATE/DELETE).

🗂️ Conteúdo do Repositório

01_ddl.sql – Criação das tabelas (DDL)

02_insert.sql – Inserção de dados (DML)

03_select.sql – Consultas com SELECT + JOIN

04_update.sql – Atualizações

05_delete.sql – Exclusões

README.md

🚀 Como executar

Criar o banco:

CREATE DATABASE biblioteca;
USE biblioteca;


Executar os scripts na ordem:

01_ddl.sql

02_insert.sql

03_select.sql

04_update.sql

05_delete.sql
